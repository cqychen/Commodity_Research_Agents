# Data Contract

`data/` is the official input boundary for the multi-agent research workflow. Do not rely on notebooks or parent research folders as the only source of production inputs.

## Fundamentals

Place SteelUnion, industry, or manually curated CSV files under:

```text
data/fundamentals/[commodity]/raw/
```

Rules:

- The first column should be the market-visible publish date whenever possible.
- Prefer `GB18030` or `UTF-8` CSV encoding.
- Use `-`, `--`, and empty strings as missing values.
- The selected latest file should be copied to, or documented in, `data/fundamentals/[commodity]/latest/`.
- As-of aligned monthly panels generated by the workflow are written to `data/fundamentals/[commodity]/processed/`.

## Market Data

Market data is split by purpose:

```text
data/market/[commodity]/daily_contracts/
data/market/[commodity]/continuous/
data/market/[commodity]/basis/
data/market/[commodity]/warehouse_receipts/
data/cache/[commodity]/
```

Continuous futures are allowed for trend, display, and volatility context, but never as the main tradable return label. Tradable labels must use real contracts or real calendar-spread pairs.
